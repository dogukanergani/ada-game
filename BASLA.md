# Başlangıç adımları

1. Kurulu olsun: VS Code (1.98 veya üstü), Node.js LTS, Git. Kontrol: `node -v` ve `git --version`.
2. VS Code'da "Claude Code" eklentisini (yayıncı: Anthropic) kur ve Claude hesabınla giriş yap.
3. VS Code'da File > Open Folder ile bu klasörü aç. GDD zaten `docs/GDD.md` içinde.
4. Claude Code panelini aç ve `PROMPT-1-cekirdek.md` dosyasının içeriğini yapıştır.
5. Önce plan çıkaracak, onayını bekleyecek. Planı oku, soruları cevapla, onay ver.

Ayrıntılı kural ve mimari: `CLAUDE.md`. İlk prototip (sadece referans): `reference/ada-v0/`.
